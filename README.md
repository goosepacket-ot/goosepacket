# Hi, I'm Laxmikant 👋

**Industrial / OT network engineer — 25+ years building and securing the networks behind plants, substations and mass-transit systems.**

I work where operational technology meets the network: Purdue-model segmentation, IEC 62443 zones & conduits, and the protocols that actually run the plant floor — Modbus, DNP3, IEC 60870-5-104, IEC 61850 (GOOSE/SV), PROFINET, S7, EtherNet/IP — carried over resilient Ethernet and WAN designs.

This profile collects the tools and labs I build to make OT networking easier to *see*, *audit* and *teach*.

---

### 🔧 What I'm building

| Project | What it does |
|---|---|
| **[ot-protocol-analyzer](https://github.com/goosepacket/ot-protocol-analyzer)** | Passive OT/ICS traffic assessment from a PCAP — asset inventory, comms matrix and security findings. Pure Python, zero dependencies. |
| **[iec62443-zone-kit](https://github.com/goosepacket/iec62443-zone-kit)** | Turns an asset list + allowed-flow baseline into an IEC 62443 zone & conduit model, firewall matrix and FR1–FR7 checklist. |
| **[netconfig-auditor](https://github.com/goosepacket/netconfig-auditor)** | Audits device configs against YAML hardening baselines (Cisco IOS + industrial), scored with remediation. |
| **[industrial-network-labs](https://github.com/goosepacket/industrial-network-labs)** | containerlab labs for OT resilience & segmentation — OSPF/BFD, VRRP, and a Purdue-DMZ firewall with a live Modbus demo. |
| **[NetStudio](https://github.com/goosepacket/netstudio-showcase)** | A desktop training app for IT/OT networking — protocols, labs, industry architectures and protocol journeys. |

---

### 🧭 Focus areas

- **OT network architecture** — Purdue model, segmentation, industrial Ethernet (PRP/HSR, RSTP/MRP), deterministic & redundant designs
- **OT cybersecurity** — IEC 62443 zones & conduits, secure remote access, passive monitoring, config hardening
- **Industrial protocols** — substation automation (IEC 61850, IEC 104), process (Modbus, PROFINET, EtherNet/IP, S7), utilities & transport
- **Sectors** — power/utilities, manufacturing, oil & gas, water, and mass transit (CBTC, FOTS, TCMS)
